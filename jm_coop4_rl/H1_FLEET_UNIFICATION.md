## 제어 및 데이터 흐름

```text
로봇별 상태 + 할당 랙 상대 위치/방향
 → 공유 상위 RL 정책(학습 대상, 10Hz)
 → 로봇별 전진/횡이동/회전 속도 명령
 → 공유 WB5 H1 보행 정책(동결, 50Hz)
 → 19개 몸체 관절 목표 + 부속 관절 유지
 → 실제 PhysX 구동(200Hz)
 → 거리·각도·속도·기울기·정지시간 측정
 → 성공/실패 판정, JSON 기록, 720p 녹화
```

실행 중 root 좌표/속도를 직접 변경하지 않는다. 초기화 시에만 관절 상태와 속도를 설정한다. 파지, 물체 부착, 삽입은 이번 범위가 아니다.

## 사전 검사

605개 활성 비로봇 collider에 대해 직선 접근 통로 AABB를 비교했다. 각 통로는 x ±0.40m, reset y−0.35부터 dock y+0.35까지, 바닥 위 0.03~1.95m로 검사했다. 지면 외 겹침은 4개 통로 모두 0개였다.

이 결과는 배치 사전 검사다. 관절별 실제 충돌 안전, 로봇끼리의 회피, 임의 위치에서의 길 찾기 성공을 보증하지 않는다.

### 확인된 연결 오류

학습 환경은 PhysX 런타임에 라디안 기준 stiffness/damping을 전달한다. 최초 평가기는 같은 숫자를 도 단위 USD angular drive에 기록하여 실효 gain이 약 57.3배 커졌다.

`eval_fleet.py`에서 USD 기록 시 `π/180`을 곱하도록 수정했다. 초기화 후 런타임에서 읽은 모든 관절 gain이 학습 계약과 같은지 assertion으로 검사하며 `gain_audit.json`에 저장한다. 체크포인트, 목표 좌표, 보상, 허용오차, 관절 각도를 임의로 바꿔서 해결한 것이 아니다.

## 진행 중 학습과 구분

`runs/h1_nav_001`은 512개 환경에서 목표 1,000회 PPO 학습을 계속한다. 이 변경을 위해 재시작하지 않았다. 월드 평가기는 저장된 checkpoint를 읽기만 한다.

학습 로그의 성공 비율은 학습 중 에피소드 지표다. 공장 전체의 독립 반복 성공률과 동일하지 않다. 이번 공장 평가는 지정된 4개 시작점에서의 단일 동시 재생이며, 10회 이상 독립 반복 검증은 별도다.

자기 충돌은 기존 동결 보행 정책 계약에 맞춰 OFF다. 따라서 모든 신체 접촉 안전까지 검증 완료로 표현하지 않는다. 학습 완료 후에는 독립 성공 횟수, 각 로봇의 정지 유지, 실제 랙 접촉, 전신 3인칭 영상을 함께 확인한다.
