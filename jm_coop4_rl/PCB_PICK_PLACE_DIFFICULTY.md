# PCB 픽앤플레이스 난이도 평가

2026-09-09. 이번 기록은 설명과 제안이며 학습 설정·월드·파지 제어를 변경하지 않는다.

## 결론

PCB 이송 자체보다, H1이 걸어와 얇은 PCB를 양손으로 실제 접촉 파지하고 다시 보행하여 내려놓는 통합 작업이 어렵다. 현재 방식은 어려운 편이다. 다만 오랜 실패를 작업 난이도나 학습량만으로 설명할 수는 없다.

| 조건 | 상대적인 구현 난이도 판단 |
|---|---|
| 고정된 산업용 팔 + 접근 공간이 넓은 지그/캐리어 | 비교적 낮음 |
| H1 정지 상태 + 낮은 개방형 랙 + 잡기 쉬운 캐리어 | 중간 |
| H1 정지 상태 + 얇은 PCB 가장자리를 양손으로 직접 파지 | 높음 |
| 위 파지에 운반 보행·정밀 배치·4대 협동까지 결합 | 매우 높음 |

위 구분은 본 프로젝트에 대한 공학적 판단이며 정량 벤치마크 점수가 아니다.

## 어려운 이유와 설정 결함의 구분

- 얇고 넓은 판은 아래 손가락 진입 공간, 접촉면, 무게중심까지 고려해야 한다. 가볍더라도 손에서 멀리 무게가 걸리면 판을 기울이는 모멘트가 생긴다.
- 양손은 서로 다른 위치에 도착하는 것뿐 아니라 하나의 판을 같은 속도로 움직여야 한다.
- H1 기본 팔은 4 DOF이고 H1-2 팔은 7 DOF다. 기본 H1에 그리퍼를 붙이는 것만으로 H1-2의 손목 자유도가 생기지는 않는다. 현재 커스텀 모델의 추가 관절과 실제 제어 가능 범위는 별도 확인해야 한다.
- 보행 때는 팔 자세와 운반 하중이 바뀌어 기존 보행 정책의 균형 유지가 그대로 보장되지 않는다.
- 물체 관통, 떠다님, 그리퍼 마운트 이탈, 잘못된 관절 단위/좌표계는 학습량으로 덮을 문제가 아니다. 물리·자산·제어 연결부터 검증해야 한다.

## 데모를 위한 권장 축소

1. 한 대만 사용하고 기존 RL로 랙 앞에 접근한 뒤 정지한다.
2. 낮은 개방형 랙에서 손가락이 PCB 밑으로 들어갈 공간을 확보한다. 정확한 높이는 현재 모델의 도달 범위를 측정해 결정한다.
3. PCB 직접 파지가 필수가 아니라면 양쪽 손잡이/파지부가 있는 캐리어를 사용한다. 이는 직접 PCB 파지와 다른 작업임을 발표에 명시한다.
4. 정지 상태에서 IK와 그리퍼 제어로 접근 → 삽입 → 닫기 → 5~10cm 리프트 → 2초 유지 → 가까운 표면에 내려놓기를 먼저 검증한다. 이 높이/시간은 다음 실험 제안이지 기존 성공 기준의 자동 변경이 아니다.
5. 실제 접촉, 물체 상승, 상대 미끄럼, 목표면 지지, 손 분리를 확인한 뒤 운반 보행을 추가한다.
6. 한 대의 전 과정이 반복 성공한 뒤 4대로 확장한다.

물리 고정으로 몸통을 붙잡은 테스트를 수행한다면 별도 진단으로 표시하며, 자유롭게 선 H1의 성공으로 간주하지 않는다. 가상 attach 사용 시에도 실제 마찰 파지와 구분한다.

현재 H1 4대의 랙 접근·정지 단일 검증 성공은 파지·운반 성공을 의미하지 않는다. 보행 정책과 IK를 나누어 사용하되 팔 제어권, 균형 유지, 전환 조건은 연결 검증이 필요하다.

## 고정 로봇팔의 입문 학습 물체 후보

사용자 후속 질문에 대한 제안이며 현재 H1 학습과 월드는 변경하지 않는다. 아래 치수는 초기 실험용 제안값으로, 산업 표준이나 특정 제품의 사양이 아니다. 실제 그리퍼 개방폭·손가락 길이·하중 한계에 맞춰 확정한다.

| 후보 | 예시 형태 | 쉬운 이유 / 주의점 |
|---|---|---|
| 정육면체 수지 블록 | 한 변 40~50mm | 평행한 두 면, 넓은 접촉면, 중심 가까이 파지. 첫 학습 최우선 |
| 직육면체 전자부품 케이스 모사품 | 40×60×30mm | PCB 공정 데모와 연결하기 쉬움. 40mm 폭 방향 파지, 돌출 핀/전선 제외 |
| 세워진 원통형 부품 모사품 | 지름 30~40mm, 높이 40~60mm | 축 회전 방향 의존도가 낮음. 곡면 접촉과 넘어짐 때문에 블록 다음 단계 |
| 두꺼운 파지 블록을 단 PCB 캐리어 | 가벼운 트레이 + 중앙/양측 파지부 | 얇은 PCB 대신 접근 가능한 두꺼운 부분을 잡음. 편심·모멘트·양손 협응 때문에 최초 블록보다 어려움 |

좋은 입문 조건: 단단함, 비교적 가벼움, 미끄럽지 않은 표면, 그리퍼 최대 개방폭보다 충분히 좁은 파지 폭, 주변 물체 간섭 없음, 무게중심 가까이 파지 가능. 얇은 판·구·전선·비닐·불규칙 금속 부품·밀집 적재·정밀 구멍 삽입은 최초 검증에서 제외한다.

### 표준 예제와 프로젝트 추천

Isaac Lab은 `Isaac-Lift-Cube-Franka-v0` 및 IK 변형, cube stacking 환경을 공식 제공한다. 설치된 `C:/IsaacLab/source/isaaclab_tasks/isaaclab_tasks/manager_based/manipulation/lift/config/franka/joint_pos_env_cfg.py`에서도 Franka·평행 그리퍼·중력이 켜진 동적 cube 구성을 확인했다. 설정 파일 존재를 실제 학습 완료나 자산 다운로드 완료로 해석하지 않는다.

robosuite도 cube lift/stack과 우유팩·시리얼 상자·캔 등의 pick-and-place를 제공한다. 이는 표준 연구 과제라는 근거이지 모든 물체가 같은 난도이거나 기본 설정에서 무조건 성공한다는 뜻은 아니다.

추천은 **Franka + 큐브 공식 예제 검증 → 직육면체 전자부품 모사품 → PCB 캐리어** 순서다. 들기와 내려놓기는 구분한다. Lift 공식 예제 성공만으로 release와 목표면 안정 배치가 검증되지는 않는다.

처음에는 시뮬레이터의 물체 위치·로봇 관절 상태를 관측으로 제공하고, 실제 중력/충돌/손가락 접촉은 유지한다. 고정 위치 들기 → 좁은 XY 범위 랜덤 위치 → 넓은 목표 트레이에 놓기 → 방향/크기 변화 → 카메라 입력 순서로 확장하는 것이 제안이다. 상태 좌표를 직접 받은 정책을 영상 인지나 VLA 성공으로 보고하지 않는다. 학습 소요시간은 실제 예제의 처리량과 독립 평가를 측정하기 전 확정하지 않는다.
