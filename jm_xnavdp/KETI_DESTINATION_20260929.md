## 변경 구조 — X-NavDP 단독이 아닌 혼합 방식

실제 카메라 RGB-D → 관측 표면의 정적 장면 기억 → 여유거리를 둔 A* 우회 안내 →
경로상 1.4m 앞 중간 목표 → X-NavDP 후보 생성/검사 → H1 보행 정책 → 물리 시뮬레이션.

- A*가 사용하는 것은 `depth_points`로 얻은 카메라 표면이다. USD 정답 장애물 좌표를 이 경로 계산에 입력하지 않는다.
- 지도 해상도 0.10m, 표면 voxel 0.05m, 계획 여유 반경 0.65m. 로봇·추종 오차를 고려해 기존 0.38m 몸체 검사보다 넉넉하게 둔다.
- 현재 위치가 계획용 여유 영역 안에 들어온 경우에만 현재 위치 반경 0.50m 이내의 짧은 탈출 연결을 허용한다. 이 연결도 실제 몸체 반경 0.38m와 셀 크기 보정을 만족해야 하며 나머지 경로는 0.65m 계획 여유를 유지한다. 목표·성공 허용오차·실행 중 안전 판정은 완화하지 않았다.
- 최종 목적지 자체는 고정한다. 중간 목표는 최종 목적지로 가는 안내 경로상에서 계산하며 원래 목표와 따로 기록한다.
- X-NavDP는 후보 32개, guidance=0.5, 실행 구간 0.8m, depth 안전 검사 기억 8회 설정을 이전 시험에서 유지한다.
- 보행 정책과 관절에 직접 손대지 않는다. X-NavDP 경로를 그대로 후보로 기록하고 검사에서 전부 실패하면 시험을 종료한다.
- 영상은 보라색=관측 기반 안내 경로, 파란색=선택한 모델 경로, 초록 원=최종 도착 영역으로 표시한다. 표시선은 모델 입력에서 숨긴다.

## 한계와 정직한 구분

이 방식은 **관측 기반 A* + X-NavDP + 기존 H1 보행**이다. X-NavDP 단독 zero-shot 우회 성공이라고 부르지 않는다.
아직 관측하지 못한 셀은 임시 통과 후보일 뿐 안전한 빈 공간이라고 증명하지 않는다.
월드 실제 기하 검사는 독립적인 시뮬레이션 중단 검사로 유지하며 경로 생성에는 쓰지 않는다.
기억은 이번 정적 상자 시나리오용이다. 이동 장애물의 과거 표면 삭제/실시간 가림 처리까지 검증한 동적 지도는 아니다.
추론 중 물리 stepping을 멈추며 카메라와 자기 위치는 시뮬레이터에서 가져온다. 실시간 하드웨어·SLAM·파지 검증이 아니다.
