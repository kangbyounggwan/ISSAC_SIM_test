# X-NavDP → H1 물리 보행 연결 / 2026-09-29

최신 후속 결과: [KETI 최종 목적지 도착·안정 정지 PASS 및 전체 720p 영상](KETI_DESTINATION_20260929.md).
009는 관측 기반 A* 중간 목표 안내를 추가한 혼합 방식으로 17초에 목표 오차 8.5cm / 기록 접촉 0N을 달성했다. 아래 001~007의 실패 기록은 당시 상태로 보존한다.

## 범위와 판정

이 문서는 정지 월드의 경로 표시 영상과 **실제로 관절 명령을 보내 물리 시뮬레이션에서 걸은 시험**을 구분한다.
이전 `VIDEO_REVIEW_20260929.md`의 24초 영상 두 개는 정지 진단 영상이다. 여기의 `*_physical_*`는 동적 H1 시험이다.

현재 실험은 로컬 RTX 4080 SUPER / Isaac Sim 5.1에서 실행했다. AWS 실행이나 새 RL 학습이 아니다.
모델은 공식 X-NavDP 고정 소스·체크포인트를 쓰며, H1 전용으로 학습된 경로 모델이라고 주장하지 않는다.
최종 채택 여부와 최신 영상은 아래 결과 절에 기록한다. 실패 실행도 보존한다.

## 연결 구조

1. JM/KETI 실제 렌더 RGB 1280×720 + image-plane depth(m)를 읽는다.
2. 시뮬레이터에서 측정한 로봇 위치·yaw와 고정 목표를 함께 X-NavDP 서비스에 전달한다. SLAM 추정은 아니다.
3. 확산 모델 후보 중 전진 가능성, 관측된 장애물 여유거리, 초기 진행 방향을 검사한 후 모델 Q가 가장 높은 후보를 선택한다.
4. 검증한 경로 구간을 속도·회전 명령으로 변환해 기존 고정 WB5 보행 정책에 전달한다.
5. 보행 정책이 19관절 명령을 생성하고 PhysX가 실제 로봇 상태를 계산한다. 루트 위치를 이동시키는 연출은 없다.
6. 최종 접근은 필요할 때 목표 위치 기반 제어기로 전환한다. 이 구간을 X-NavDP가 단독 제어했다고 표시하지 않는다.
7. 접촉·넘어짐·안전거리 위반·유효 경로 없음이면 **시뮬레이션 시험을 종료**한다. 실제 하드웨어의 안전 정지 성능을 뜻하지 않는다.

중요: `policy_lower_corrected.pt`는 이름과 달리 다리만이 아니라 팔·몸통을 포함하는 BODY_19 계약이다. 69차원 관측을 사용하며 가중치·관절 기본값·PD 계수는 변경하지 않았다.

## 추론·경로 설정 변경

### 후보 수

정지 관측을 고정하고 모델 시드 42에서 8/16개 후보를 비교했다(`candidate_compare_001/comparison.json`). 두 월드 모두 유효 후보가 있었다.
이후 물리 주행 중 후보가 모두 거부되는 시점의 관측에서도 8/16/32개를 비교했다(`failed_observation_comparison_001.json`).
후자는 기억 상태를 초기화한 단일 관측 비교이므로 **실제 주행의 시간 이력을 재현한 결과가 아니다**.
후보 수가 늘었다고 전 구간 성공을 보장하지 않는다. 영상 렌더도 비트 단위 결정론을 보장하지 않는다.

### 경로 유지 가중치

기본 guidance=0.5(마지막 두 후보 0.05)를 0으로만 바꾼 KETI 시험은 더 일찍 막혀 채택하지 않았다.
후보 선택 이후에는 거부된 Q-best가 아니라 **실제로 선택한 후보**를 다음 추론의 경로 이력으로 넘긴다.

### 실행 구간 길이

긴 예측 전체가 장애물에 걸리면 가까운 구간까지 실행할 수 없었다.
KETI에서 `commit_horizon=0.8m`를 별도 비교했다. 이는 충돌 반경을 줄이는 것이 아니라 **다음에 실행할 구간을 제한하고 재관측하는 방법**이다.
목표를 넘어가는 부분은 원래 목표의 수직 평면에서 자른다. 목표 좌표 자체는 이동하지 않는다.
0.8m 이후 원본 예측이 안전하다고 간주하지 않으며 원본 16개 경로를 모두 저장한다.
이 모드에서 다음 추론의 이력도 채택한 구간만 24점으로 재표본화한다. 장애물로 향하는 폐기한 뒷부분을 계속 따라가게 하지 않는다.

### 마지막 접근·정지

- `path`: 모델 경로 추종 후 도착 거리 안에서 정지·방향 정렬.
- `rack_rl`: 기존 model_200.pt를 마지막 0.8m에서 연결한 비교. JM에서 안전거리 위반으로 실패하여 채택하지 않음.
- `goal_pose`: 마지막 0.8m에서 고정 목표를 향해 감속. 최대 전진 0.3m/s, 마지막 0.3m에서 목표 yaw를 정렬하며 도착 거리 안에서는 전진 명령 0. 관절을 수동 고정하거나 텔레포트하지 않음.

### 가까운 장애물이 시야 아래로 빠지는 문제

KETI-005의 6.5초 시점: 실제 상자 모서리에 가까워졌지만 해당 프레임만 사용한 선택 경로의 관측 여유거리가 0.994m로 기록됐다.
머리 높이 카메라에서 가까운 낮은 상자가 아래쪽 시야 밖으로 나가, 최신 depth 표면만 검사하면 사라진 것으로 취급하는 문제다.
이어 6.9초에 독립 USD 몸체 검사가 여유거리 -10.6mm를 감지해 종료했다. 기록된 실제 접촉은 0N이나 안전거리 위반이므로 실패다.

`--depth-memory-frames 8`은 최근 실제 관측 표면을 측정한 로봇 위치·yaw로 월드 좌표에 변환해 최대 8회 유지한다(정상 호출 주기에서 약 4초).
새로운 정답 지도나 월드 장애물 좌표를 모델에 주는 것이 아니다. 모델 추론 입력은 그대로이고 안전 필터의 관측 기억만 추가한다.
`audit_depth_memory.py`로 **동일한 KETI-005 입력·출력 후보를 고정한 재검사**를 수행했다.
기존 선택 경로는 5.5초부터 거부됐으며, 6.0/6.5초에는 유효 후보가 없었다(`depth_memory_replay_005.json`).
따라서 안전거리 위반 이전에 이 경로를 차단하는 효과는 새 물리 실행의 렌더 차이와 분리해 확인했다.
이는 정적 장애물 시험용 보수적 관측 기억이다. 움직인 물체의 과거 위치가 남는 문제와 시야 밖 장시간 장애물을 모두 해결한 동적 지도는 아니다.

## 입력과 디버그 영상 분리

초기 물리 시험에서는 파란 경로 표시선이 모델용 RGB-D에도 보일 수 있었다. 이 영향이 섞인 시험을 최종 검증으로 사용하지 않는다.
이후 실행은 `/World/XNavDPTrial/Debug`를 모델 관측 때 숨기고, 촬영할 때만 다시 표시한다.
영상 우측 하단은 현재 카메라 장식 화면이 아니라 **마지막으로 실제 추론에 보낸 RGB와 시각**이다.
초록 원은 원래 도착 허용 반경을 보여 주는 영상용 표시이며 모델 입력이나 물리 collider에 포함되지 않는다.

## 한계 — 반드시 결과와 함께 읽을 것

- 추론 중 물리 stepping을 멈춘 동기식 연결이다. 영상 시간은 시뮬레이션 시간이며 실시간 처리속도 인증이 아니다.
- 관측된 depth 표면 검사는 가려진 빈 공간을 증명하지 않는다. 별도로 USD 실제 기하의 몸체 여유거리 검사를 수행해 시험을 중단할 수 있다. 이 기하를 모델 입력이나 A* 대체 경로로 쓰지 않았다.
- self-collision은 기존 보행 계약대로 비활성이다. 손·몸통 등 모든 자기 충돌이 검증됐다고 해석하면 안 된다.
- JM에서 H1_1만 동적으로 시험한다. 나머지 로봇·물건은 정적 배경이다. 네 대 협동·파지·제품 운반 검증은 범위 밖이다.
- 기존 JM의 정적 배경 로봇에서 mimic joint 경고가 발생한다. 제어 H1_1의 동적 관절·collider·접촉 센서는 별도 확인했고 원본 USD는 수정하지 않았다. 배경 물리 구성 정리는 후속 작업이다.
- 단일 시드의 성공은 랜덤 스폰·가림·이동 장애물에 대한 성공률이 아니다.

따라서 현재 확정 가능한 것은 JM의 해당 시작 조건에서의 접근·정지 구성과 두 월드의 실제 보행 연결이다. **KETI의 전 구간 경로는 확정하지 않는다.**

다음 작업은 안전 gate 완화나 보행 재학습이 아니라, 장애물에 가까워지기 전 일관된 우회 방향을 선택하는 경로 후보 평가와 H1 전진·회전 실행 가능성의 연결이다.
관측 기억을 모델의 후보 선택/경로 비용에도 반영하는 방안을 별도 실험으로 비교해야 한다. 이후 KETI 최종 방향 정렬·정지, 여러 seed, 가림 및 움직이는 장애물, 비동기 실시간 추종 순서로 확대한다.

시험 총 11회(JM 4회, KETI 7회), 연결 계층 단위 테스트 24개 통과. 모든 시험의 영상 전체 프레임을 디코딩 검증했다.
