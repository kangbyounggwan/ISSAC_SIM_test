# KETI X-NavDP 단독 경로계획 비교 — 2026-09-30

## 시험 목적과 범위

사용자 요청: X-NavDP의 단독 성능 확인. 기존 혼합 방식 성공 `keti_physical_009`와 비교하여 **A* 중간 목표 안내만 끈다**.
여기서 단독은 경로 생성의 단독이며, RGB-D 전처리·관측 안전 필터·경로 추종 제어·고정 H1 보행 정책·정지 판정은 유지한다.
공식 모델 그대로의 벤치마크, 모든 보조 제어 제거, 실시간 하드웨어 시험이라는 의미가 아니다.

안전 필터는 관측 표면 거리(몸체 반경 0.38m), 후진, 초기 방향, 진행 길이를 검사한다. 모든 후보가 탈락하면 임의 경로로 대체하거나 허용오차를 늘리지 않고 종료한다.

### 마지막 후보가 거부된 이유

`inference_035.json`의 32개 후보 전부 탈락. 사유는 중복 집계다.

- `REVERSE`: 31개 — 몸체 기준 X가 -2cm 아래이거나 경로의 X 감소량이 2cm보다 큼.
- `HEADING`: 30개 — 추종 기준점 방향이 전방 ±60°를 벗어남.
- `INSUFFICIENT_PROGRESS`: 10개 — 요구되는 최소 진행 길이 미달.
- `OBSERVED_SURFACE_CLEARANCE`: 0개 — 마지막 후보들은 관측 장애물 거리 때문에 탈락한 것이 아니다.

확인된 직접 원인은 **모델이 생성한 근거리 경로와 현재 전진 중심 H1 추종 제약의 불일치**다. 모델이 왜 이러한 후보를 생성했는지(이력 guidance, 목표 도달 동작, 학습 분포 차이 등)는 이번 한 번의 실행으로 분리하지 못한다. 특정 원인으로 단정하거나 모델 자체가 목표를 모른다고 해석하지 않는다.
