## 목적과 현재 구현

케티/SMIC 공장 통로에서 H1이 주황색 박스를 우회하는 동작을 1280×720으로 촬영한다.
직선 경로, 우회 계획, 실제 이동 궤적을 구분하여 경로계획 알고리즘이 작동한 이유를 보여준다.
**센서 기반 인식, UniLM-Nav 실행, 새 장애물 회피 RL 학습으로 표시하지 않는다.**

| 역할 | 사용 방식 |
|---|---|
| 환경 | `smic_world/smic_world.usd`, 원본 읽기 전용 |
| 장애물 정보 | 시뮬레이터 USD의 실제 authored 좌표·충돌체 경계; 카메라/라이다 입력 아님 |
| 경로계획 | A* 8방향 탐색, 모서리 끼어 지나가기 금지, 선분 간섭 재검사 후 단순화 |
| 주행 지시 | 실제 몸체 위치에 따른 경로 추종 → 전진/회전 속도 |
| 보행 | 기존 WB5 `policy_lower_corrected.pt`, 69 관측 → 19 관절, 학습 가중치 보존 |
| 도착 정지 | 초기 path 방식과 기존 model_200 재사용 방식을 분리 비교 |
| 녹화 | 전체 몸체 3인칭 720p/24fps + 계획/실측 궤적 미니맵 |

기존 KETI 전시용 H1 두 대는 링크 collider가 없어 동적 보행에 재사용하지 않는다.
촬영 세션에서만 전시용 로봇을 비활성화하고, 검증된 standalone H1 한 대를 넣는다.
배경 제품은 정적 장애물로 취급한다. 설비/레이아웃과 원본 USD는 저장·수정하지 않는다.
전체 세계 고정이나 로봇 좌표 이동으로 걷기를 흉내 내지 않는다.

## 사전에 고정한 시나리오

- 출발 `(5.0, 3.8)` m, 목적지 `(10.4, 3.8)` m, 바닥 z=0, 최종 yaw=0°.
- 박스 크기 0.65×0.55×0.65 m. 정적 충돌체로 생성한다.
- 직선 거리의 40~60% 지점, 좌우 ±0.18 m에서 seed당 한 번 추출한다.
- 사전 seed 42, 43, 44. 성공할 때까지 위치를 다시 뽑지 않는다.
- A* 격자 0.10 m, 장애물 경계 확장 0.75 m. 실제 발 배치/손 전체를 정확히 나타내는 형상은 아니다.
- 실제 몸체 중심 기반 제외 반경 0.38 m와 랜덤 장애물-로봇 접촉력도 별도로 감시한다.
- 보행 요청 최대 0.40 m/s, 회전 0.45 rad/s. 자세 초기화 후 1초 안정화한다.
- 도착: 거리 <0.18 m, 속도 <0.10 m/s, 방향 <15°, 회전속도 <0.15 rad/s,
  기울기 <15° 조건을 1초 유지한다. 제한 시간 45초.
- 접촉력 >0.20 N, 몸체 제외영역 침범, 낙상은 실패. 허용오차/목적지 자동 수정 없음.

## 화면 구성

- 빨간 점선: 출발점과 목적지를 잇는 직선, 박스 때문에 막힘.
- 녹색 선: 현재 배치로 A*가 계산한 우회 계획.
- 파란 선: 영상 미니맵에 표시한 **실측 pelvis 이동 궤적**.
- 상단: seed, 시간, 단계, 목적지 거리, 측정 접촉력.

원본은 시작부터 실패 종료까지 보존한다. 별도 13초 발췌본은 모든 프레임에
`중간 검증: 우회 구간 발췌 | 전체 실행의 최종 정지는 실패`라고 명시했다.
발췌본의 종료를 목적지 정지 성공으로 보지 않는다.

## 1차 검사와 발견

장애물 없는 경로 길이는 5.40 m다. 원본 환경의 높이 관련 경계를 읽어 장애물 237개를 기록했다.
세 seed 모두 직선이 막히고 다른 우회 경로가 계산됐다. 경로 테스트 8개 통과.
이는 계획 검사 결과이며 3회 동적 성공을 뜻하지 않는다.

`smoke_seed42_001`: 실제 H1이 접촉 없이 장애물을 우회했으나 **목적지 정지 TIMEOUT**.
45초 시점 목적지 오차 0.401 m, 최대 랜덤 장애물 접촉 0 N.
목적지에 가까워진 뒤 0 속도 명령만으로 완전히 멈추지 않고 앞으로 밀렸고,
다시 목표를 향해 회전하면서 도착 영역을 벗어났다. 파지나 IK 문제와 별개다.

다음 실험의 단일 변수는 **목적지 0.8 m 이내의 종료 제어기**다.
목표·경로·박스 seed·보행 모델·관절·허용오차는 고정하고,
`--terminal-controller rack_rl`로 기존 18→3 model_200을 최종 접근에만 재사용한다.
WB5 학습 설정에서 전진 명령 범위가 0~1 m/s임을 확인했으므로,
정지를 위해 검증 없이 음수 전진 명령을 추가하지 않는다.

### 프레임 검토

2초(출발), 10초(박스 우측 경계 통과 직전), 마지막 16.64초(정지 전환 실패)를 직접 확인했다.
전체 몸체가 걷고 우회하는 모습과 지도상의 실제 궤적이 대응한다.
마지막 목적지 부근에서는 우측 하단 미니맵이 발 부분을 일부 가린다.
다음 전체 성공 촬영에서는 미니맵을 좌측 하단으로 옮기는 것이 필요하다.
이번 원본 영상의 실패를 가리기 위해 영상 내용을 재합성하지 않았다.

### 다음 우선순위

우회 경로계획 자체를 새로 학습시키기보다 **기존 보행의 제동·정지 균형을 별도 짧은 실험으로 검증**한다.
발 지지와 몸체/무게중심 상태를 함께 사용하고, 걷는 자세를 그대로 고정하는 두 실패 방식을

정지가 검증되면 seed 42/43/44를 같은 설정으로 각각 처음부터 촬영한다.
현재는 3개 정적 계획만 있으며 다른 seed의 동적 성공을 주장하지 않는다.

## 파일과 실행

| 파일 | 내용 |
|---|---|
| `config.json` | 고정 장면/주행/판정 조건 |

## 검증 경계

접촉 필터는 랜덤 박스와 로봇 링크 사이를 검사한다. 다른 설비와의 안전은 이 버전에서
몸체 중심 기반 경계로 보조 검사하므로 전체 mesh 충돌 안전 인증은 아니다.
보행 정책을 보존하기 위해 자기충돌은 기존처럼 OFF이며 별도 한계다.
장애물 배치는 주행 전에 알려져 있고, 주행 중 새 물체 인식/회피나 이동 장애물은 다루지 않는다.
실행은 로컬 RTX 4080 SUPER이며 AWS 학습을 시작하지 않는다. Git push/merge는 수행하지 않는다.
Fable 외부 검토는 내부 정보 전송 승인 문제가 해결되지 않아 실행하지 않았다. Fable 합의로 표시하지 않는다.
